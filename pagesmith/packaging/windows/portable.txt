Pagesmith portable mode

While this file sits next to pagesmith.exe, Pagesmith keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PagesmithData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Pagesmith with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Pagesmith and
%LOCALAPPDATA%\Pagesmith) instead. If PagesmithData can't be written (for example on a read-only
drive), Pagesmith says so and uses the per-user folders instead.
