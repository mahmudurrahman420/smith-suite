Yes. Pixelsmith is one of the Crafting Apps, which the project describes as free, open-source creative tools. The code is licensed under MIT or Apache 2.0, your choice, and is on [GitHub](https://github.com/mahmudurrahman420/pixelsmith).

Pixelsmith works offline. Its smart selection tools run on your computer, with no cloud and no account.

The Smith Suite name, wordmark and anvil mark in `docs/brand/` are original work by Shohan (mahmudurrahman420), licensed under the project licence (MIT OR Apache-2.0).

See [Install Pixelsmith](../getting-started/install.md) to download it.
