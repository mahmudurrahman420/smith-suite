# Anysmith app icon

An anvil with two sparks, in paper `#f2f1ee` and spark yellow `#ffd35c` on a rounded tile in
Smith Suite blue `#4e7bfb` (512-unit tile, 110-unit corners). Original work by Shohan
(mahmudurrahman420), MIT OR Apache-2.0: see `LICENSE.txt`.

Files:

- `anysmith.svg`: the master artwork (also `hicolor/scalable/apps/`).
- `anysmith-1024.png` and `hicolor/<size>/apps/*.png`: rendered with `rsvg-convert`.
- `anysmith.ico`: ImageMagick, sizes 16–256. `anysmith.icns`: Pillow.
