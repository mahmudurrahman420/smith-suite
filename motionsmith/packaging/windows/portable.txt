Motionsmith portable mode

While this file sits next to motionsmith.exe, Motionsmith keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the MotionsmithData folder beside it instead of
%APPDATA%\Motionsmith. Copy the whole folder to move Motionsmith with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Motionsmith unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Motionsmith) instead.
If MotionsmithData can't be written (for example on a read-only drive), Motionsmith logs a
warning and uses %APPDATA%\Motionsmith instead.
